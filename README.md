# Krishi Mitra

Krishi Mitra is an agriculture support application developed to help farmers with crop-related information, farming guidance, and resource management.

## Features
- Crop information system
- Farming guidance
- Location-based support
- User-friendly interface

## Technologies Used
- HTML
- CSS
- JavaScript

## Purpose
The project aims to provide digital agricultural support and improve accessibility for farmers through technology-driven solutions.
